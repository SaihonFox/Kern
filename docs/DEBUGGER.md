# Отладчик `kernc debug`

```
kernc debug <файл.kern> [аргумент ...]
kernc debug <папка> [аргумент ...]
```

Компилирует программу так же, как `kernc run` (файл, проект по соглашению или
`build.kern`), и запускает `main` под интерактивным отладчиком. Аргументы после исходника
передаются в `main(list<str> args)`.

## Команды

| Команда | Действие |
|---|---|
| `continue`, `c` | продолжить до следующей точки останова |
| `step`, `s` | выполнить следующую инструкцию (войти в вызов) |
| `next`, `n` | следующая инструкция в текущем кадре |
| `finish`, `f` | до возврата из текущего кадра |
| `break`, `b <строка>` | точка останова в текущем файле |
| `break <файл>:<строка>` | точка останова по файлу и строке |
| `break <функция>` | остановиться при входе в функцию |
| `delete`, `d <id|all>` | удалить точку останова |
| `info`, `i` | список точек останова |
| `locals`, `l` | локальные слоты текущего кадра (с именами) |
| `stack`, `bt`, `where` | стек кадров |
| `print`, `p <имя>` | значение локальной переменной |
| `print <слот>` | значение слота |
| `print <выражение>` | `+ - * / %`, скобки, литералы, имена локальных |
| `help`, `h`, `?` | справка |
| `quit`, `q` | прервать программу (код возврата 130) |

Пустая строка повторяет `continue`.

## Что видно

- Первая остановка — на входе в `main`.
- `locals` печатает имена слотов (`$`, параметры и локальные переменные) из таблицы
  имён в `.kbc` (версия 4). Для временных слотов без имени — `paramN`/`slotN`.
- `print value + 1` считает простое выражение над локальными; вызовы функций, поля,
  индексы и `match` в отладочных выражениях не поддерживаются.
- Строки берутся из `LineTable` функций (debug info включён по умолчанию).

## Ограничения

- Отладчик работает в том же потоке, что и VM; `await` и планировщик не дают
  «заморозить» программу во время ожидания внешнего события.
- Нет attach к уже запущенному процессу и удалённой отладки (протокол не выбран;
  см. `DECISIONS_NEEDED.md`).
- Пауза проверяется перед каждой инструкцией, поэтому на больших циклах отладка
  заметно медленнее обычного запуска.

## API для встраивания

`Kern.Vm.Execution.IDebugHook`:

```csharp
bool ShouldPause(FunctionDef function, int offset, int? line, int frameCount);
bool Pause(DebugPauseInfo pause); // true — продолжить, false — DebugAbortedException
```

`DebugPauseInfo` содержит имя функции, файл, строку, смещение, число кадров, локальные
слоты, их имена и стек `DebugFrameInfo`. Точки останова и шаг реализует хук; VM только сообщает
позицию перед инструкцией. CLI-реализация — `Kern.Cli.Debug.ConsoleDebugger`.
