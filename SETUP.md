# SETUP — установка opencode и подключение ключа (Windows)

У вас: Windows, .NET 10 SDK, Node.js, Git. Ключ посредника вида `sk-…`, адрес API неизвестен. Ничего из этого я не мог проверить в вашей среде — если шаг не работает, пришлите мне вывод.

## 1. Установка opencode
```powershell
npm install -g opencode-ai
opencode --version
```
Если `opencode` не находится — закройте и откройте PowerShell (PATH обновляется). Альтернативы: `scoop install opencode` или `choco install opencode`.
Официальные инструкции для Windows иногда советуют WSL; нам он не нужен (dotnet у вас нативный) — работаем в обычном PowerShell.

Версия важна: у opencode есть «старый» (v1) и «новый» (v2) формат файлов агентов. Скрипт умеет оба — формат задаётся в `models.json` (`"format": "v1"` или `"v2"`). Начните с `v1`. Если при запуске opencode жалуется на неизвестные поля `permission`/`temperature`/`steps` — смените на `v2` и снова запустите `apply-models`. Если жалуется на `permissions` — верните `v1`.

## 2. Папка проекта
Распакуйте пакет, например, в `C:\Kern-agents`. Все команды ниже — из этой папки.

## 3. Какая модель (рекомендация)
| Роль в `models.json` | Кто | Модель | Зачем |
|---|---|---|---|
| `lead` | lead, reviewer | **Claude Opus 5.5** | Мало ходов, но самые дорогие по смыслу: планирование, ревью, трудные места (binder/flow-analysis, линковка .kbc) |
| `dev` | compiler-dev, vm-dev, std-dev, cli-dev, qa | **Claude Sonnet 5.5** | Основной объём кода; лучшее соотношение цена/качество |
| `cheap` | mechanic | **Claude Haiku 4.5** | `using`, табы/CRLF, переименования, перевод spec |

Если у посредника нет Opus — поставьте Sonnet и в `lead`, и в `dev`. Если нет Sonnet 5.5 — берите самую новую Sonnet/Opus из списка. Fable 5.1 — только как «тяжёлая артиллерия» для одной застрявшей задачи (дорого, в базовую конфигурацию не включаю).
Точные id моделей (например `claude-sonnet-5-5`) у посредника могут называться иначе — их покажет шаг 4.

## 4. Узнать адрес API и список моделей (у вас есть только ключ)
1. Найдите в кабинете/на сайте/в чате посредника строки «Base URL», «API endpoint» или «OpenAI-compatible». Обычно это что-то вроде `https://api.<сайт>/v1`. Без адреса настроить нельзя.
2. Проверка (ключ не сохраняется и не печатается):
```powershell
$env:KERN_PROBE_KEY = "sk-ВАШ_КЛЮЧ"
node tools/probe-provider.mjs https://АДРЕС_ПОСРЕДНИКА
```
Скрипт сам пробует варианты `/models` и `/v1/models` в стилях OpenAI и Anthropic и печатает: **стиль**, **baseURL** и **id моделей**, похожих на Claude.
3. Проверочный запрос к конкретной модели (тратит ~20 токенов):
```powershell
node tools/probe-provider.mjs https://АДРЕС_ПОСРЕДНИКА --chat claude-sonnet-5-5
```
4. После теста закройте окно или выполните `Remove-Item Env:KERN_PROBE_KEY`.

## 5. Заполнить `models.json`
Пример для посредника со стилем OpenAI (самый частый):
```json
{
	"format": "v1",
	"provider": {
		"id": "proxy",
		"name": "Мой посредник",
		"npm": "@ai-sdk/openai-compatible",
		"baseURL": "https://АДРЕС_ПОСРЕДНИКА/v1",
		"models": {
			"claude-opus-5-5": { "name": "Opus 5.5" },
			"claude-sonnet-5-5": { "name": "Sonnet 5.5" },
			"claude-haiku-4-5": { "name": "Haiku 4.5" }
		}
	},
	"models": {
		"lead": "proxy/claude-opus-5-5",
		"dev": "proxy/claude-sonnet-5-5",
		"cheap": "proxy/claude-haiku-4-5"
	}
}
```
Если зонд показал стиль **anthropic** — замените `"npm"` на `"@ai-sdk/anthropic"` и `baseURL` на найденный. Ключи `models` внутри `provider` — **точные id** из вывода зонда; в `models.lead/dev/cheap` пишется `id-провайдера/id-модели`.

## 6. Ввести ключ (один раз)
```powershell
opencode auth login
```
Выберите **Other**, введите id провайдера (`proxy`, как в `provider.id`) и вставьте ключ. Он сохранится в `%USERPROFILE%\.local\share\opencode\auth.json`, а не в папке проекта. Никому не отправляйте этот файл и ключ, не вставляйте его в чат с агентами.

## 7. Сгенерировать агентов
```powershell
node tools/apply-models.mjs
```
Создаст `.opencode/agents/*.md` (8 агентов) и `opencode.jsonc`. Повторяйте после любого изменения `models.json`.

## 8. Запуск
```powershell
opencode
```
- `Tab` — переключение основных агентов; выберите **lead**. Команда `/models` покажет доступные модели.
- Вставьте стартовое сообщение из `PROMPTS.md`.
- Подагенты (compiler-dev, vm-dev, …) lead вызывает сам; вручную — `@compiler-dev сделай …`.
- `Esc` — остановить текущий шаг. Если агент зациклился — остановите и напишите ему «стоп, опиши, что не получается».

## 9. Права агентов (по вашему выбору)
Агенты могут свободно: править файлы проекта, запускать `dotnet build/test/run/format/restore/new/sln/add/clean`, `node tools/*`, читать (`dir/ls/type/cat/grep/rg/findstr`), создавать папки. **Всё остальное — спрашивают у вас** (подтверждаете в окне). `git` и опасное удаление (`rm -rf`, `del /s`, `rmdir /s`, `Remove-Item -Recurse`) запрещены. Если окно подтверждения появляется слишком часто на безопасную команду — добавьте её в `agents-src/agents.json` → `common.bash` и снова запустите `apply-models`.

## 10. Бюджет токенов
Прочитайте `docs/TOKEN_BUDGET.md`. Главное: короткие сессии (одна задача — одна сессия), логи в файлы, не просить агентов читать большие файлы целиком. Раз в этап смотрите остаток у посредника и пишите его в `STATUS.md`. Планово первый этап укладывается в ~42M из 60M.

## 11. Когда что-то не работает
| Симптом | Что делать |
|---|---|
| `opencode` не найден | Новое окно PowerShell; `npm config get prefix` — этот путь должен быть в PATH |
| Ошибка конфигурации при старте | Смените `format` v1↔v2 в `models.json`, `apply-models`; пришлите мне текст ошибки |
| «Model not found» | id в `models.json` должен совпадать с id из зонда; проверьте `provider.models` и перезапустите opencode |
| 401/403 | Неверный ключ/адрес; повторите `opencode auth login`; проверьте зондом |
| 429 / лимиты | Подождите; уменьшите параллельность (не запускайте несколько сессий сразу) |
| Агент «читает всё подряд» и жжёт токены | Остановите; напомните: «читай по диапазонам, см. TOKEN_BUDGET.md» |
| Агент хочет выполнить странную команду | Не подтверждайте; ответьте «нет, используй dotnet/node tools» |

## 12. Что делать, когда агенты просят решение
Открывайте `DECISIONS_NEEDED.md`: у каждого вопроса есть варианты и рекомендация. Напишите под вопросом `ANSWER: A` (или своё) и скажите lead: «обработай DECISIONS_NEEDED».
