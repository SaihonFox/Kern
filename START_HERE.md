# Kern — пакет для агентов (читать первым)

Это папка, из которой агенты (opencode) строят язык Kern **с нуля**. Агенты — отдельные экземпляры Claude: они знают только то, что лежит в этих файлах, поэтому здесь собрано всё.

## Что где
| Путь | Назначение |
|---|---|
| `AGENTS.md` | Правила для всех агентов (opencode читает его сам) |
| `docs/` | Спецификация языка, решения, дорожная карта, билдер, ловушки, бюджет токенов |
| `examples/` | 31 пример — будущие golden-тесты |
| `reference/` | Старая (ни разу не собиравшаяся) реализация — только как источник идей |
| `agents-src/`, `models.json`, `tools/apply-models.mjs` | Описание ролей агентов и настройка моделей |
| `STATUS.md`, `DECISIONS_NEEDED.md`, `CHANGELOG_LANG.md`, `logs/` | Отчёты агентов вам |
| `SETUP.md` | Пошаговая установка opencode и подключение вашего ключа |
| `PROMPTS.md` | Готовые сообщения, которые вы вставляете агенту |

## Пять шагов
1. Распакуйте архив, например в `C:\Kern-agents`, откройте там PowerShell.
2. `npm install -g opencode-ai`, затем `opencode --version`.
3. Узнайте адрес API посредника и проверьте ключ: `node tools/probe-provider.mjs <адрес>` (см. `SETUP.md`, шаг 4).
4. Впишите модели в `models.json`, выполните `opencode auth login`, затем `node tools/apply-models.mjs`.
5. Запустите `opencode` в этой папке, выберите агента `lead` (клавиша Tab) и вставьте стартовое сообщение из `PROMPTS.md`.

Рекомендованные модели: **lead и reviewer — Opus 5.5**, **разработчики — Sonnet 5.5**, **mechanic — Haiku 4.5** (подробнее в `SETUP.md`, раздел «Какая модель»).
