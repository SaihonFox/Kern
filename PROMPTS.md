# PROMPTS — что вставлять агенту

## Старт (агент `lead`, один раз)
```
Ты — lead проекта Kern. Прочитай AGENTS.md, docs/README.md, docs/ROADMAP.md, docs/DECISIONS.md и docs/TOKEN_BUDGET.md (остальное — по мере надобности).
Начни с M0: создай каркас решения (Kern.slnx, проекты из docs/CONVENTIONS.md, тестовый проект с KernHarness и GoldenTests), добейся
dotnet build = 0 ошибок и dotnet test = зелёный, node tools/check-style.mjs = чисто. Поручи mechanic перевод docs/spec/kern.en.md на английский (docs/spec/kern.en.md),
а reviewer — выборочную проверку перевода. Работай короткими задачами через подагентов, обновляй STATUS.md, вопросы пиши в DECISIONS_NEEDED.md. Затем переходи к M1.
```

## Продолжить в новой сессии (каждый раз, чтобы не раздувать контекст)
```
Продолжи проект Kern. Прочитай STATUS.md и текущий этап в docs/ROADMAP.md, возьми следующий небольшой кусок, выполни его через подходящего подагента,
проверь dotnet build и dotnet test, обнови STATUS.md. Остановись после этого куска и коротко отчитайся.
```

## Обработать мои ответы
```
Я ответил на вопросы в DECISIONS_NEEDED.md. Перенеси решения в docs/DECISIONS.md и spec (если это решения по языку — и в CHANGELOG_LANG.md), удали отвеченные вопросы, учти их в работе.
```

## Проверка бюджета и состояния
```
Дай краткий отчёт: какой этап, сколько тестов проходит, что сломано, сколько токенов потрачено по твоей оценке и достаточно ли на следующий этап. Не больше 15 строк.
```

## Если решение оказалось плохим
```
Остановись. Опиши в DECISIONS_NEEDED.md: что не получается, почему, 2–3 варианта выхода с рекомендацией и стоимостью каждого. Пока я не отвечу, работай над несвязанными задачами.
```

## Принять этап
```
Проведи приёмку этапа M<N> по критериям из docs/ROADMAP.md: запусти build, test, check-style, golden-тесты; вызови reviewer; опиши расхождения со спецификацией. Не закрывай этап, пока всё не зелёное.
```
